# CADalog — Product context

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Static HTML, CSS and vanilla JavaScript, published from the public Grand-Code40/CADalog repository via GitHub Pages when the repository owner enables Pages. No server, database, runtime frameworks, or paid integrations.

## Purpose
An independent, functional directory of companies that convert paper technical drawings, PDFs, scanned images and sketches into editable CAD drawings. The purpose is to help people find specialist providers and compare publicly described capabilities, while giving providers a genuine reason to join or update their profile.

## Audience & jobs
People seeking a drawing conversion provider: engineers, production staff, architects, procurement teams and technical researchers. They need to find a relevant company quickly, filter by service/discipline, verify the services from original sources, and reach the provider directly.

## Confirmed product behavior
Search, service and discipline filters, alphabetical sort, saved entries stored in localStorage, individual company profiles, outbound source/company links, and an optional suggestion form which opens a pre-filled GitHub issue. The directory currently contains twelve entries, assembled from companies' published services; the source links are not endorsements.

## Boundaries and evidence
No invented ratings, rankings, testimonials, project photographs or claims that a provider was independently evaluated. No simulated UI, unearned social proof or misleading submission success. The site must remain useful with JavaScript only for interactive controls and preserve keyboard/accessibility support.
