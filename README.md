# CADalog

Независимый каталог 12 компаний, которые переводят бумажные чертежи, сканы, эскизы и PDF в редактируемые CAD-файлы. Русский — по умолчанию, английский — через **EN** или `?lang=en`.

## Текущая версия
- Спокойный зелёно-сланцевый акцент; адаптивные карточки в 3 / 2 / 1 колонки.
- Десять настоящих логотипов/favicon из официальных сайтов. Для двух записей — название текстом. Источники, проверка загрузки и ограничения прав: `SOURCES.md`.
- Поиск на двух языках, фильтр услуги и несколько тегов одновременно. Теги объединяются по **И**; клик по тегу карточки выбирает этот тег.
- Профили, услуги, форматы, прямые ссылки на исходные материалы. Поиск/теги/язык сохраняются **в URL**, не в браузерном хранилище.
- Краткий справочник по выбору услуги и список материалов для расчёта стоимости.
- **Избранное/закладки полностью удалены.** Код не читает и не изменяет старые записи хранилища.
- **Нет ссылок или форм GitHub.** Контактный адрес не выдуман: его можно добавить в footer после подтверждения владельцем.

## Запуск
```bash
python -m http.server 8000
```
Откройте `http://localhost:8000/`. Сборщик, серверная логика и runtime-зависимости не нужны.

Примеры: `?lang=en`, `?company=powerkh`, `?tag=Architecture&tag=DWG`.

## Проверки
```bash
node --check app.js
node --check directory.js
node --check locales.js
node --check data.js
node --test tests/*.test.cjs
```
14 тестов проходят. Проверяются фильтрация по нескольким тегам, поиск, URL, RU/EN и целостность записей. Это не замена браузерному QA. Состояние проверки — в `QA.md`.

В среде с Playwright и доступным Chromium, после запуска локального HTTP-сервера:
```bash
CADALOG_URL=http://localhost:8000/ node tests/browser-check.cjs
```
Этот отдельный скрипт **не был выполнен до конца здесь**: песочница блокирует запуск Chromium. Он создаёт скриншоты для ручной проверки, если браузер доступен.

## Файлы
- `index.html`, `styles.css`: страница и стили.
- `app.js`: карточки, профили, переключение языка, события и fallback логотипов.
- `directory.js`: чистая логика фильтров и URL.
- `data.js`: 12 исходных записей, теги, официальные URL и provenance логотипов.
- `locales.js`: тексты интерфейса RU/EN и переводы описаний.
- `SOURCES.md`: происхождение записей и изображений, ограничения.
- `PRODUCT.md`, `DESIGN.md`, `RESEARCH.md`, `QA.md`: контекст и проверка.

## Ограничения содержимого
Сведения составлены по открытым материалам компаний. Уточняйте состав работ и условия непосредственно у исполнителя. На `globalcadservices.com` сейчас используется бренд **DraftPoint CAD**; карточка сохраняет исходное название и показывает предупреждение, поскольку связь брендов не установлена.

Логотипы используются для идентификации компаний, а не как примеры проектов. Публичный URL не означает свободную лицензию. Фотографии и чертежи не скопированы. Внешние изображения могут быть недоступны; тогда остаётся название компании.
