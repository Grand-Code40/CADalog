# CADalog

Независимый каталог 12 компаний, которые переводят бумажные чертежи, сканы, эскизы и PDF в редактируемые CAD-файлы. Русский — по умолчанию, английский — через **EN** или `?lang=en`.

## Текущая локальная версия
- Белый фон, графитовый текст и синие действия. Карточки с рамкой 1px и почти прямыми углами 2px; адаптивная сетка 3 / 2 / 1 колонки.
- Десять официальных логотипов/site icons; ещё две компании представлены названием. Ошибка загрузки изображения оставляет настоящее название. Provenance — в `SOURCES.md`.
- Поиск на двух языках, по словам и префиксам независимо от их порядка. Имена вида `Convert2CAD` находятся по `Convert 2 CAD`; поддерживаются ограниченные алиасы. Только полный запрос `Cat 2` получает резервное исправление при отсутствии точного совпадения.
- Фильтр услуги и четыре тематических тега: архитектура, инженерия, геодезия/инфраструктура, разные направления. Теги объединяются по **И**. Форматы DWG/DXF/DGN и CAD со слоями остаются в карточках и поиске, но не являются отдельными фильтрами.
- Фиксированный алфавитный порядок. Старые format-tag и sort URL-параметры не ограничивают выдачу. Переключатель порядка и поясняющая строка тегов удалены.
- Профили и самостоятельная страница **«Источники и принципы каталога»** (`?page=sources`). Навигация сохраняет поиск, услугу, тематические теги и язык.
- **«Предложить компанию»** — редактируемый текстовый шаблон и копирование. Отправка не подключена, что прямо сказано в интерфейсе. При недоступном Clipboard API текст выделяется для ручного копирования. Ни GitHub, ни выдуманного email, ни ложного подтверждения отправки нет.
- Нет аккаунтов, избранного, localStorage, трекинга или backend.

## Запуск
```bash
python -m http.server 8000
```
Откройте `http://localhost:8000/`. Сборщик и runtime-зависимости не нужны.

Примеры: `?lang=en`, `?company=powerkh`, `?page=sources`, `?tag=Architecture`, `?q=Convert+2+CAD`.

## Проверки
```bash
node --check app.js
node --check directory.js
node --check locales.js
node --check data.js
node --test tests/*.test.cjs
```
**42 unit/static теста проходят.**

Необязательные DOM-тесты, с dev-зависимостью вне проекта:
```bash
npm install --prefix /tmp/cadalog-dom-runtime --cache /tmp/cadalog-npm-cache happy-dom@21.0.4 --ignore-scripts --no-audit --no-fund
CADALOG_DOM_MODULE=/tmp/cadalog-dom-runtime/node_modules/happy-dom \
  node --disallow-code-generation-from-strings --frozen-intrinsics --test tests/dom-check.cjs
```
**15 DOM-тестов проходят.** Они не загружают сеть и не подменяют визуальную проверку браузером. Node сообщает экспериментальный статус `--frozen-intrinsics`; это не ошибка тестов.

В среде с Playwright и Chromium, после запуска локального HTTP-сервера:
```bash
CADALOG_URL=http://localhost:8000/ node tests/browser-check.cjs
```
Обновлённый browser-check проверяет RU/EN на шести ширинах, источники/профили/возврат, тематические фильтры, старые URL и копирование. Здесь Chromium блокируется средой до открытия страницы; визуальный проход не заявлен завершённым. Подробнее — `QA.md`.

## Файлы
- `index.html`, `styles.css`: разметка и стили.
- `app.js`: карточки, профили, источник/навигация, события и копирование.
- `directory.js`: чистая логика поиска, фильтров и URL.
- `data.js`: неизменённые 12 записей, официальные URL и provenance логотипов.
- `locales.js`: RU/EN.
- `tests/`: unit/static, DOM и необязательный браузерный runner.
- `PRODUCT.md`, `DESIGN.md`, `QA.md`: контекст и ограничения проверки.

## Ограничения и публикация
На `globalcadservices.com` используется бренд **DraftPoint CAD**; исходное имя записи сохранено с предупреждением, поскольку связь брендов не установлена. Публичный URL логотипа не означает свободную лицензию; портфолио и чертежи не копируются.

Семь файлов сайта: `index.html`, `styles.css`, `app.js`, `directory.js`, `locales.js`, `data.js`, `favicon.svg`. Ссылки относительные, рассчитаны на корень домена и `/CADalog/`.

Рабочая копия: `/workspace/shared/cadalog-navigation-oct29`. Ничего не опубликовано и не отправлено в удалённый репозиторий. Это не полный Git-клон: сохраняйте реальные workflows репозитория. Для настоящей отправки предложений нужен подтверждённый канал владельца.
